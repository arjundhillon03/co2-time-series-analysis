# Time Series Forecasting in R

## Overview

This project explores time series forecasting techniques using R and the Prophet forecasting library.

The analysis investigates historical atmospheric CO₂ concentration data and applies forecasting models to predict future trends using statistical and time series methods.

The project also includes regression analysis, trend decomposition, seasonality analysis, and data visualisation to better understand long-term behaviour in the dataset.

---

## Objectives

- Analyse historical atmospheric CO₂ concentration data
- Apply forecasting models using Prophet
- Investigate trend and seasonal patterns
- Compare different forecasting horizons
- Develop practical experience in time series analysis and statistical modelling
